# Schmackofatz
*A meal plan app for Leipzig, written in Flutter using beautiful Material UI 3*

[<img src="https://gitlab.com/IzzyOnDroid/repo/-/raw/master/assets/IzzyOnDroidButtonGreyBorder_nofont.png" height="50" alt="Get it at IzzyOnDroid">](https://apt.izzysoft.de/packages/schmackofatz)

## Installation
### Install Droid-ify and install through IzzyOnDroid-Repo (recommended)
1. Head over to [Droid-ify Client releases](https://github.com/Droid-ify/client/releases) and install the latest `app-release.apk`

   You probably have to set your browser as a trustable source for installing apps, you can disable this after installing Droid-ify in your phone settings.
3. On first start, activate IzzyOnDroid Repo. (It should be pre-selected)
4. Select the search-icon on the top right and search for "Schmackofatz"
5. Select the app with the plate icon and install it.

   You probably have to set Droid-ify as a trustable source for installing apps. You should not unset this, else updates cannot be installed until you re-enable it.

## Development
Pull requests are very welcome!
For development, install the given version of Flutter mentioned at `pubspec.yaml` and your favorite IDE (I prefer Android Studio over Visual Studio Code). 

Then clone the repo and open it in your IDE, maybe install the dependencies if not done automatically:
```bash
flutter pub get
```
