# Schmackofatz
*Der Speiseplan für alle Mensen in Leipzig, gebaut mit Flutter und Material UI 3*

[<img src="https://gitlab.com/IzzyOnDroid/repo/-/raw/master/assets/IzzyOnDroidButtonGreyBorder_nofont.png" height="50" alt="Get it at IzzyOnDroid">](https://apt.izzysoft.de/packages/space.pleura.schmackofatz)

## Installation
### Installation über Droid-ify mit IzzyOnDroid (empfohlener Weg)
1. Gehe auf die [Droid-ify Client releases-Seite](https://github.com/Droid-ify/client/releases) und installiere die neuste `app-release.apk`

   Du musst vermutlich für deinen Browser aktivieren, dass er als "unbekannte Quelle" Apps installieren darf. Du kannst das nach der Installation von Droid-ify gerne wieder deaktivieren.
3. Beim Start sollte die IzzyOnDroid-Repo bereits ausgewählt sein. Wenn nicht, dann wähle sie aus und fahre fort.
4. Suche mit Hilfe des Such-Icons oben rechts in der Ecke nach "Schmackofatz".
5. Wähle die App mit dem Teller-Icon aus und installiere sie.

   Auch hier musst du erstmal Droid-ify erlauben, dass es als "unbekannte Quelle" Apps installieren darf. Das solltest du nicht deaktiveren, sonst musst du es für jedes Update wieder aktivieren.
